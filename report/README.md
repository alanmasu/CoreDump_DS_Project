# Project report

The four LaTeX source files preserve the structure and page geometry of the official
`ds1_project_2026_report_template.zip` archive.

Compile from this directory with:

```bash
tectonic main.tex
```

The submitted artifact is `RizzoMasutti_Report.pdf`. Its page count must remain at or
below the six-page limit in the project specification; the committed version is exactly
six A4 pages.
